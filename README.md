# lab4 traps

本实验涉及了中断、系统调用和信号处理的实现，主要内容是实现一个周期性的alarm机制，允许用户程序在指定的时间间隔内执行一个handler函数。

## RISC-V assembly

我们需要了解RISC-V的调用约定，特别是寄存器的使用和系统调用的实现方式。同时基本了解RISC-V的汇编代码，看懂内核中定义的一些中断向量。

你需要完成：

1. 了解RISC-V的调用约定。
2. 阅读简单的RISC-V汇编代码。
3. 明确什么是大端序和小端序。

## Backtrap

我们需要实现一个简单的回溯程序来打印堆栈信息。

你需要完成：

1. 了解程序栈空间的基本结构。
2. 了解各寄存器的作用。
3. 实现一个简单的回溯程序来打印堆栈地址。

## Alarm

我们需要实现一个周期性的alarm机制，允许用户程序在指定的时间间隔内执行一个handler函数。

你需要完成：

1. 实现sigalarm系统调用。
2. 详细了解xv6处理中断的路由流程。
2. 当其为时钟中断时进行检查和累加。
3. 实现sigreturn系统调用来返回到被中断的程序。
